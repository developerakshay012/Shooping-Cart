# 🛒 Shopping Cart

A modern **Shopping Cart Application** built using **React**, **Redux**, and **Tailwind CSS**.  
This project demonstrates how to manage state efficiently using Redux and create a responsive, user-friendly UI with Tailwind CSS.

---

## 🚀 Features

- 🧠 **Redux State Management** – Add, remove, and update products seamlessly.  
- 💰 **Dynamic Total Calculation** – Automatically updates cart total in real-time.  
- 📱 **Responsive Design** – Fully responsive layout built with Tailwind CSS.  
- ⚡ **Fast and Scalable** – Built with reusable components for smooth performance.  
- 🛍️ **Product Display** – Shows product list with image, title, and description.  

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **State Management:** Redux Toolkit  
- **Styling:** Tailwind CSS  
- **Build Tool:** Vite
